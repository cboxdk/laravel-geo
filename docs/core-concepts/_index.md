# Core concepts

Two ideas carry the package:

- [Jurisdictions](jurisdictions.md) — the resolved country/subdivision key that
  seller registrations, addresses, rate sources and tax regimes all bind to.
- [Tax profiles](tax-profiles.md) — the structural tax attributes this package
  adds on top of raw ISO geography.
